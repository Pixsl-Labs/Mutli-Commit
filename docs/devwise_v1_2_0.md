# DevWise v1.2.0

## Added

- Renamed app branding from Multi-Commit to DevWise.
- Added local Branch → Issue → Task checklist workflow.
- Added local issues store under the existing config directory for compatibility.
- Added Create Issue From Selected inside checklist.
- Added Create/Switch Branch from an active issue.
- Added Focus Mode.
- Added Project Templates.
- Added safe clutter cleanup for patch backup files.

## Compatibility note

The runtime config directory intentionally remains compatible with the existing Multi-Commit config path for now so existing projects, checklists, commands and settings do not disappear during the rename.
